Week 1 June 1 - 7

Goals

  • Watch Keras api tutorial and begin reading deep learning book
  • Read main paper related to demo paper and example demo papers
  • Begin writing demo paper based on the DNN mutation analysis accelerator demo tool DM#
  • Explore DM# demo tool repository and start creating an accompanying ReadMe

Approach and implementation

On Monday and Tuesday, I dedicated the time to watch the Keras api turorial and program along the tutorial creating the same models demonstrated within the video. To do this I utilized and familirized myself with the programming environment JupyterLab. I also spent time working through the assigned deep learning book, completing the first few chapters.

On Wednesday, I read and took notes on the assigned research paper and the example demo papers provided by my mentor. After reading the assigned readings I had a better idea of the "academic" tone and writing style needed for our demo paper. Addtionally, I now had an understanding of the DM# demo tool, which will now allow me to start drafting the sections of the demo paper.

Next, I explored the code base for the repository of the demo tool. Using the notes I took about the repository my lab partners and I began drafting the ReadMe. I started this process by creating and sharing a google document for us to work on. Within this document I created the overall outline of the ReadMe, which allowed my group to split up the tasks for completing the sections of the ReadME.

Throughout the whole week I had been writing the first drafts for the demo paper. To start this process, I drafted the introduction and abstract sections of the paper. I really focused on trying to maintain the academic tone while writing. Once I completed these drafts I asked my mentor and fellow lab partners for feedback.

Results

  • Completed the Keras API tutorial and progressed through first chapters of deep learning book
