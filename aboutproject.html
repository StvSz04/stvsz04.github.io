About Project

Title: Accelerating Mutation Analysis of Deep Neural Networks.

Project Overview & Goal:

Deep Neural Networks (DNN) are used in many areas, including mission- and safety-critical domains. Therefore, quality assurance of DNNs is quite important. Among many methods for quality assurance of DNNs testing is a widely used approach, but good performance on testing does not always guarantee generality, robustness, or safety of the models after their deployment. Therefore, there is a need for systematic way for assessing the quality of test datasets. Mutation analysis has recently been reintroduced in the context of DNNs as a promising method for test dataset quality assessment. DNN mutation analysis has been used in many applications beyond its original purpose in assessing test dataset quality. Despite this potential, DNN mutation analysis is extremely costly. In this project, we will explore various methods for accelerating DNN mutation analysis to make this promising technique practical.

Current Progress:

We recently submitted a tool demonstration paper to SPLASH/ISSTA 2026. This paper explains the engineering details of a demo tool called DM#, a refactored version of the original tool [1] designed to be more user-friendly and maintainable. The main goal of DM# is to accelerate DNN mutation analysis using Fourier analysis and clustering to reduce the number of mutants tested.
