Approach and implementation

On Wednesday, my lab group met to discuss how we want to approach refactoring the existing paper's repository. This task was given to us because we need to modernize this repository to use current libraries and refactor the code to be more efficient for our next project. During this meeting, we identified the major tasks needed to be done and divided them among ourselves.

While refactoring the repository we transferred all the core backend logic to a new repository, and built a command line interface wrapper around the logic. The main idea for this was to provide and accessible interface with the backend logic, becuase the repository before was designed for experiments and not as a tool.

For our next project we are going to use this newly modernized and refactored tool.
